# Human vs AI Comparison

| Alert                             | AI Classification | Manual Classification | Comparison        | Notes                                                                                                                                                                                                                                                                                                                                                                                                                |
| --------------------------------- | ----------------- | --------------------- | ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Alert 01 — New Local User Created | Needs review      | Needs review          | Aligned           | The AI correctly identified the local account creation, mapped it to T1136.001, and recognized that the available evidence did not establish whether the action was authorized or malicious. It avoided assuming persistence, malware, or account compromise.                                                                                                                                                        |
| Alert 02 — Suspicious PowerShell  | Needs review      | Needs review          | Partially aligned | The classification matched, but the AI assigned low risk while the manual assessment assigned medium risk. Both recognized the PowerShell execution as requiring context rather than treating it as confirmed malicious activity. The T1059.001 mapping was well supported, while T1046 remained low-confidence because the command tested one known internal Splunk service rather than performing broad discovery. |
| Alert 03 — Noisy False Positive   | Benign            | Benign                | Aligned           | The AI correctly recognized `cmd.exe /c whoami` as benign in the documented Splunk visibility test context. It did not treat the command shell or user-discovery behavior alone as evidence of malicious activity.                                                                                                                                                                                                   |

## Summary

The only material difference was Alert 02, where the AI and manual assessment agreed on the `needs_review` classification but assigned different risk levels.
